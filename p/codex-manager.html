详细介绍

它是什么

Codex CLI 的配置都藏在 ~/.codex/config.toml 里 —— 手工编辑容易破坏格式、丢失注释、记不住字段名。tcm 把这些变成直观界面：表单编辑、下拉选择、掩码输入，并且只改动你触碰的键，注释与排版原样保留。

功能

概览：Codex 版本、当前生效模型/供应商、密钥就绪状态、备份统计。全局设置：model / model_provider / approval_policy / sandbox_mode / model_reasoning_effort / model_verbosity 等常用键，表单 + 下拉编辑，留空即删除该键。

模型设置：上下文窗口 model_context_window（Codex 直接生效）与最大输出 tokens model_max_output_tokens，正整数校验，概览页同步展示。

模型供应商：[model_providers.*] 增删改查，wire_api（responses / chat）下拉，支持 key = value 高级自定义字段，新建时可直接保存 API Key。配置档案：[profiles.*] 增删改查，一键「应用为全局」，配合 codex --profile <名称> 使用。

安全设计

外科手术式编辑：只修改目标键，注释、空行、键顺序、其余字段字节级保留。

自动备份：每次写盘前备份到 ~/.codex/backups/，保留最近 30 份，应用内可恢复。先校验后落盘：TOML 不合法直接拒绝保存，坏配置进不了你的 ~/.codex。

密钥安全：掩码输入、默认打码显示，auth.json / env.sh 权限 0600。OpenAI 官方 Key 写入 auth.json 的 OPENAI_API_KEY；自定义供应商（DeepSeek / OpenRouter / Kimi …）的 Key 持久化到 ~/.codex/env.sh，按 i 向 ~/.zshrc / ~/.bashrc 注入带标记的 source 行。

命令行模式：tcm list、tcm use fast、tcm doctor —— use 沿用同样的外科手术式编辑与自动备份，doctor 只检查本地状态，不发网络请求、不消耗额度。

下载与安装

需要 Go 1.25+ 才能 go install；国内网络可设 GOPROXY=https://goproxy.cn,direct。

sudo install -m 0755 tcm-linux-amd64 /usr/local/bin/tcm
# 或 go install / or go install
go install github.com/ZhehaoTetsuhiro/Codex-Manager@latest
# 或源码构建 / or from source
git clone https://github.com/ZhehaoTetsuhiro/Codex-Manager.git
cd Codex-Manager && make install   # 装到 ~/.local/bin/tcm
tcm list && tcm doctor
