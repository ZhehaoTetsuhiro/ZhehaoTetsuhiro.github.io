详细介绍

它是什么

一套关于「在函数计算器上编程」的完整作品：一本 78 页（中英各一版）的书，加一个用 Lean 4 从零写的 991/999 模拟器 —— 书里的每个构造都能在模拟器上逐步复现。

你拥有的全部工具是「一条条用 : 相连的语句」和「一次一次的 EXE」。布尔逻辑藏进阶跃函数 OZ 里，循环只此一家 Σ(f(x),x,a,b)，取整函数族 Rnd/RNI 承担截断与取模，多语句链就是循环的程序计数器，标记位给链装上记忆，终止语句 B÷(1−B) 用 Math ERROR 结束程序、防止多按。

引子：下面这一行表达式，在 991/999 上按一次 EXE，就能判定 2<A<10⁸ 内任意整数是否为素数（1 素数 / 0 合数）：

1-OZ(e^(Σ(ln(OZ((cos(Aπ/x))²)+1), x=2, RNI(√A−1/2)))-1)

原理：x 整除 A 时 cos(Aπ/x)=±1，其平方经 ln 后贡献 0；OZ 是手工构造的阶跃函数（借计算器 15 位内部精度与 10⁻¹⁰ 量级的小量把「是否为零」变成 0/1），RNI 把内部 15 位值截断为显示精度 —— 整条公式把整除性、全称量词与布尔化全部压缩进一次求值。完整构造、正确性证明与推广（因子和、GCD、Pell 方程、蒙特卡洛……）见配套书籍。

模拟器

Lean 4 实现，复现真机行为：15 位十进制算术、Math/Syntax/Argument ERROR、多语句链（每按一句、回绕、出错复位 —— 也就是循环的程序计数器语义）、语句级 STO 校验、变量 A–F x y z、ANS、函数记忆 f(x)/g(x)、EXE 次数（或范围）模拟。

.tc 文件描述一条语句链，模拟器可以逐步执行或按 EXE 次数批量跑：

cd simulator && lake build
.lake/build/bin/tcc ../examples/prime.tc  → 输出 0：3721=61² 是合数
.lake/build/bin/tcc ../examples/prime.tc 10 20  → 对范围内每个 EXE 次数模拟

书与仓库

《Casio Coding 从入门到精通》：语句与多语句链编程基础、程序成本（EXE 复杂度、以 Σ 求和次数计的时间复杂度、空间复杂度）、绝对值与 OZ 布尔逻辑、取整函数族、Σ 求和、标记位与终止语句、数论应用（素数判定的完整证明、因子和、GCD、Pell 方程）、迭代与数值方法、复数/多项式/矩阵、函数记忆、精度理论与错误大全。

仓库结构：simulator/（Lean 4 模拟器）、documents/zh/ 与 documents/en/（各 78 页，黑白印刷风格，xelatex 编译）、examples/（.tc 示例）、tests/（错误检测用例）。

致谢：基本思路与设想（包括素数判定函数等核心构造）由 ZhehaoTetsuhiro 提出；完善、文档撰写与模拟器实现由 Kimi K3 完成。
