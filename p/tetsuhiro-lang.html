详细介绍

它是什么

一门认真的语言，用文言写：.浩 是源界，编译器 zhc 把界译成 AMD64 汇编，经系统 as 与 ld 铸为无 libc 的静态 Linux 可执行文件 —— 不是解释器，不是玩具转译。

界以「哲浩御世」开篇，以「归源」收官；误犯则本源垂示于误途（哲浩垂示：……），其行归一。

例/首例.浩：

哲浩御世。
注曰「首例——万物之首要示现：问候本源」

「浩哉，哲浩御世之界！」宣。
二、三加五乘宣。  注曰「得二十五」
九根宣。  注曰「得三」
「浩」三乘宣。  注曰「得「浩浩浩」」
归源。

make build && zhc/zhc 例/首例.浩 -o 首例 --run →
浩哉，哲浩御世之界！ / 25 / 3.0 / 浩浩浩

语言设计

纯文言语法：无空格、无外邦符号；名号书于 《》，文辞书于 「」，数书汉数（三十四、三点一四），注以 注曰「……」。

栈式核心：诸敕皆与栈相往来，复 弃 换 凌 转 五字运栈；术（函数）循「栈之礼」—— 受参自栈取，成果留栈顶。

带标记值：64 位 tagged value，低三位记其类 —— 数、虚、阴阳、文、列、典、浮。

经籍模块：承 字可纳经卷（.浩 源界）与典册（.哲），经经相承，允许互相引用而不会循环展开。

编译器用法：zhc <界.浩> [-o 出] [-s 出.s] [--run]；界中可取化生「外众」（一列），得命令行所附之众。

下载与安装

编译器本身是静态二进制，但铸界需要系统里有 as 与 ld（binutils）；产物是 x86-64 Linux 静态 ELF。
