详细介绍

它是什么

一台用 Go 从零写起的波动光学「示波器」：内核可以当库用（import "twos/optics"），也可以起一个 HTTP 服务，在浏览器里搭光路、看图像/相位/偏振/立体视图。

设计取向是「物理优先」：能用解析解对照的地方就对照，数值有效性问题（采样、奈奎斯特带限、衰逝波）主动告警而不是悄悄给你一张好看的图。

数值内核

自研并行 FFT（支持非 2 的幂网格，Bluestein 算法）、角谱法 ASM（亥姆霍兹方程精确解）及其三个高精度变体（零填充 asm_pad、离轴频移 asm_shift、两者结合）、菲涅耳（两种形式）与夫琅禾费远场；衰逝波处理、奈奎斯特带限正则化、菲涅耳数与采样有效性自动告警。

高级传播：全矢量角谱法（重构纵向分量 Ez，非傍轴）、非均匀/复折射率介质（split-step BPM，分层/梯度/吸收/增益）、宽带谱叠加（polychromatic）、部分相干光（Gaussian Schell 模型）、各向异性/双折射介质（单轴晶体与 Berreman 4×4 双轴晶体）、3-D 体传播（一次传播输出 x,y,z 体积场）。

元件与光路模型

20+ 种可调参数元件：透镜、光阑、光栅、轴锥镜、波带片、涡旋相位板、楔形棱镜、漫射体、反射镜、凹面/凸面镜、泽尼克像差板、偏振片、波片、旋光片、自定义琼斯矩阵、分束器、合束器、单轴/双轴晶体、均匀介质……

脚本元件让「新元件」不需要重编译：把复透过率写成 elements/<名字>.json 里的表达式（相位、幅度、可选琼斯矩阵 + 参数表），加载后与内置元件同等可用（GUI 插入对话框、参数面板、场景 JSON、Go API），服务端每 2 秒自动热重载（新增、改写、删除都跟上），定型后可 -gen-go 打印等价的原生 Go 元件。

定位场景光路（1.0 光路模型）：光路存的是元件的位置与几何形状（scene.components[]），而不是「依次经过的元件序列」；光线路径由最近命中与反射/透射几何推导。元件带真实轮廓（圆/方/矩形/椭圆/三角/环/多边形/双缝/十字/星形/超椭圆/自定义顶点/细缝），轮廓即通光孔径；旧的序列配置可一键自动转换（POST /api/convert）。

多光源与相干分组：任意多个光源，各有位置/方向/波长/功率/偏振与相干组；同组同波长相干叠加产生干涉条纹，不同组/波长按强度叠加，每个平面保留各光源的复场可按通道单独查看。图像视图按波长→线性 sRGB（CIE 1931 拟合）真实着色。

量子光学与测量视图

量子光学：Fock 基线性光学内核，支持 Fock/相干/压缩/双模压缩/热态输入与相移、分束器、位移、压缩、损耗门，输出光子数分布、g²(0)、正交分量与联合分布 —— Hong-Ou-Mandel、单光子马赫-曾德尔、压缩、EPR 与混合态/损耗效应都可复现，图表可导出 PNG/SVG。

偏振与相位：斯托克斯参数、偏振椭圆（ψ/χ/轴比/手性）、偏振度、二维相位去包裹与波前 PV/RMS；点击图像上任意一点展开该点的琼斯矢量、斯托克斯参数与相位。立体视图渲染整套光路（元件板、按光源着色与相对功率的光束段、遮挡、平台网格）。

精度验证：143 项物理与数值测试 —— 艾里斑峰值与暗环、单缝 sinc²、光栅 Raman-Nath 级数、双缝条纹、高斯束腰演化与 Gouy 相位、琼斯计算、马赫-曾德尔/迈克尔逊能量守恒、波带片效率、散斑对比度、功率守恒、Fresnel/ASM 互证与复场级解析解对比、双折射/Berreman、部分相干、宽带谱、HOM/相干/压缩/Fock 量子统计等。

GUI 与接入

浏览器 GUI 鼠标与键盘双可用：视图标签条 1 图像 / 2 相位 / 3 偏振 / 4-6 各分量强度 / 7-8 分量相位 / 0 立体视图，16 个内置模板，n 新建、o 打开、s 保存配置 JSON、m 切换量子光学模式、h 隐藏中心图样、自定义网格大小、毛玻璃视觉主题。

内核即库（import "twos/optics"），HTTP API 供任意语言调用（示例含 Python 客户端），并可选 -tags cuda 启用 CUDA/cuFFT 后端：所有走 FFT 的路径自动加速，无 CUDA 设备时安全回退 CPU。
