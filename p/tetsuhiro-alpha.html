详细介绍

它是什么

tthr 是 Tetsuhiro 指令集架构（TH-ISA）的参考实现，一个可执行的 128 位机器：解释器负责取指、译码、执行、陷阱与分页，两遍汇编器把汇编源码变成 .tthr 镜像，反汇编器与交互式单步调试器负责看清机器在做什么。

整个工具链只用 Go 标准库，没有第三方依赖；go build -o tthr . 就能得到一个零依赖静态二进制。

指令集覆盖

基础整数：LB…LQ 全宽度访存、算术逻辑、立即数、7 位移位、全部分支与跳转、LUI/AUIPC、FENCE、CSR 指令组。

M 扩展：128 位 MUL/MULH*/DIV*/REM*，含除零与溢出语义。A 扩展：LR/SC 与 AMO*（.w/.d/.q，含 min/max 的有无符号变体）。

F/D 扩展：32 个浮点寄存器、FLEN=128 与 NaN-box，五种舍入模式 + 动态舍入、融合乘加、fclass/比较/转换，NaN、符号零与单次舍入语义严格实现（软浮点，正确性优先）。

T 安全扩展：tattest（HMAC-SHA256 密钥化测量）、tseal/tunseal（AES-128），仅 T 特权级可执行。

C 扩展：16 位压缩指令，取指在 16 位边界上动态切换压缩/非压缩译码，反汇编器能处理混合流；汇编器对 c.* 不做自动放宽（越界直接报错，绝不静默生成错误代码）。

V 扩展（向量）：沿用 RVV 1.0 编码与语法，VLEN=128 / ELEN=64 —— 配置、单元步长/跨步/索引/段/整寄存器访存与首错即停、整数运算/乘除/乘加、定点舍入与饱和、加宽收窄、比较/掩码逻辑/归约、浮点运算与融合乘加/转换/比较/归约/加宽、gather/compress/iota。

模拟器与调试

四级特权模型 T > M > D > S，陷阱陷入与 xRET 返回、异常委托链 （tdeleg → medeleg → dedeleg）、逐级 CSR 访问权限校验、向量/直接陷阱向量与中断仲裁。

Sv128 分页（15 级、16 字节 PTE、超级页、A/D 与 U 位）与 PMP 强制（TOR/NA4/NAPOT、R/W/X、L 锁、tprot 锁）；稀疏 128 位地址空间按 4 KiB 页按需分配。

CLI：run（--steps/--trace/--regs/--mem）、step 交互式单步、disasm、asm、version；主机 I/O 走 tohost 寄存器，写偶数即退出、写 (字节<<8)|1 即打印。

按 go test ./... 会对 samples/ 下每个示例做端到端断言（汇编 → 载入 → 执行 → 校验退出码），新增示例必须登记期望值，否则测试会提醒补登记。
